A single out-of-office email auto-reply of 166 characters, painfully honest about the sender's absence and inbox, yet polite enough that a manager would let it stand. Produced deterministically by `main.py` using only the Python standard library.

> I'm out of office. I'm not checking email, which is the whole point of being away. I'll reply in the order messages arrived — eventually. Thank you for understanding.

## Run it

```sh
python3 main.py
```

This writes the reply to `entry.txt` (next to `main.py`) and to `/output/entry.txt`, and prints it.
